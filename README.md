# Tic-Tac-Toe Web Application

A classic Tic-Tac-Toe game where two players can play against each other in the browser.

## 🚀 Features

- Two-player mode
- Game state tracking
- Win detection logic
- Draw detection
- Restart game option
- Responsive UI

## 🛠️ Tech Stack

- HTML5
- CSS3 (Grid layout)
- JavaScript (Game Logic & Event Handling)

## 📂 Project Structure

├── index.html  
├── style.css  
└── script.js  

## 📌 Game Logic

- Maintains a 3x3 array to track moves.
- Checks winning combinations after each move.
- Displays winner or draw message.
- Disables board after game ends.

## ▶️ How to Run

1. Clone the repository
2. Open `index.html`

## 🎯 Learning Outcome

- Arrays and conditional logic
- Game state management
- Algorithmic thinking
